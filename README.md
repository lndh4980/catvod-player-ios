# CatVodPlayer - 影视仓 iOS 播放器

支持影视仓/CatVod JSON 配置格式的 iOS 原生播放器。

## 功能特性

✅ **直播源播放**
- 支持 m3u/m3u8 格式
- 展示直播源列表

✅ **点播站点**
- 展示所有站点列表
- 支持搜索过滤

✅ **配置管理**
- 自定义配置地址
- 自动保存配置

✅ **播放器**
- 基于 AVPlayer
- 支持多种视频格式

## 安装方式

### TrollStore 安装（推荐）

1. 下载 IPA 文件
2. 使用 TrollStore 安装
3. 支持 iOS 16.0+

## 配置地址

支持标准的影视仓 JSON 格式，例如：

```
https://qist.wyfc.qzz.io/fty.json
```

## 技术栈

- Swift 5.9
- SwiftUI
- AVKit
- iOS 16.0+
